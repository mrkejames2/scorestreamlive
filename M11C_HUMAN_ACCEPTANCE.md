# M11-C Human Acceptance — Broadcast Clock

M11-C certifies clock behavior suitable for a long-running browser source.

- [ ] Open the same overlay on two devices/browsers.
- [ ] Open the Control Center on the iPhone.
- [ ] Do not refresh either overlay.
- [ ] Start First Half.
- [ ] Both overlay clocks start automatically.
- [ ] Both overlay clocks remain visually aligned with each other.
- [ ] Control Center and overlay remain within approximately one second.
- [ ] Allow the game to run for at least 60–90 seconds.
- [ ] No obvious drift develops between overlay instances.
- [ ] End First Half; both overlays stop automatically.
- [ ] Both overlays show the same stopped time.
- [ ] Start Second Half; both overlays move to the authoritative second-half base and run.
- [ ] Background one browser/tab for at least 30 seconds if practical.
- [ ] Return to it; it automatically re-anchors to authoritative game state.
- [ ] Disconnect one overlay briefly, then reconnect.
- [ ] Reconnected overlay catches up automatically.
- [ ] No manual refresh is required.
- [ ] No score/lifecycle behavior from M11-B regressed.
