# M18-G1 — Club Branding Domain + Storage

Creates the durable, tenant-safe foundation for premium Club branding. G1 includes one optional branding row per Club, DIRECTOR + CUSTOM_OVERLAY_BRANDING protected API, PNG/JPEG/WebP validation, dedicated durable storage, immutable asset delivery, and an Alembic migration. G1 intentionally does not change overlay/broadcast rendering; G2 adds the Director editor and G3 integrates rendering.
