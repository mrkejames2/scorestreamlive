# M18-G2 — Branding Management UX

G2 adds the Director-facing premium branding management experience on top of G1.

- `/account/branding`
- entitlement-aware locked state
- display/short name editing
- primary/secondary color editing
- logo upload/removal
- live preview
- G1 API reuse

G2 does not modify overlay/broadcast rendering; that remains M18-G3.
