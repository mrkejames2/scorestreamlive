ScoreStreamLive Engineering Principles

1. The application must always remain deployable.

2. Every milestone must build successfully.

3. Docker is the development environment.

4. Render is the production environment.

5. Simplicity beats cleverness.

6. Every change should have one clear purpose.

7. Do not introduce unnecessary dependencies.

8. Do not redesign previously approved architecture without explanation.

9. Documentation is part of the product.

10. The goal is a maintainable SaaS, not a demo application.
