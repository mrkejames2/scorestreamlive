# M11-G Release Notes

M11-G introduces no new product behavior.

It is the final Milestone 11 release/certification gate and verifies:
- M11-A read-only broadcast overlay
- M11-B live Socket.IO synchronization
- M11-C clock precision
- M11-D broadcast visual presentation
- M11-E goal presentation
- M11-F match-state presentation
- M11-F post-acceptance cross-display clock synchronization fix
- Control Center and Overlay shared monotonic timing model
- five-second authoritative clock re-anchoring on both displays
- read-only overlay
- transparent OBS/Streamlabs canvas
- no clock:tick architecture

Human release requirement:
Control Center and Overlay must remain within 1 second over a five-minute side-by-side test.
